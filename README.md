# 媽媽的午餐小日子

新莊午餐抽籤網站，支援選店、查看精選菜單、抽選或勾選餐點、分享與家人共用清單。

## 使用方式

GitHub Pages 提供前端網頁。新增店家與最近一次選餐由既有的 ChatGPT Site 雲端 API 和 D1 資料庫保存，跨手機共用；GitHub Pages 本身不保存資料。若停用該 Site，雲端同步會失效。

網站和同步 API 均可被知道網址的人使用，請勿放入私人資料。餐點及參考價格可能變動，請以店家為準。

`backend/` 保存同步 API 與資料庫結構的參考原始碼；它需要支援 Cloudflare D1 的伺服器環境，不能直接由 GitHub Pages 執行。
